# GhostBug roadmap

## v0.1 (included here)

- [x] CLI for Chromium recording and local replay
- [x] Same-origin JSON/text API response fixtures
- [x] All form text values redacted by default
- [x] Deterministic Playwright test generation
- [x] User-defined expected UI text
- [x] Demonstration of a red-to-green regression test
- [x] Unit tests, CI template, docs and MIT license

## v0.2 (proposed)

- [ ] Visual timeline to inspect, edit and delete captured actions
- [ ] Interactive approved/exported fixtures, more precise secret scanning
- [ ] Better selector generation (roles, labels, stable fallbacks)
- [ ] Support navigation, waits and scoped assertions
- [ ] Cross-platform smoke tests and a more polished CLI

## v0.3 (proposed)

- [ ] Shareable `.ghostbug` reproduction bundle
- [ ] GitHub issue attachment/export workflow
- [ ] Network replay beyond naive method+path matching
- [ ] Optional differential replay between app versions

## v1.0 (aspirational)

- [ ] Browser extension / Firefox support
- [ ] Robust multi-page sessions
- [ ] Optional local AI-assisted explanation
- [ ] Stable JSON schema migration and security audit

We won't promise a star count or timeline. Decisions should follow feedback and reliable reproductions, not vanity metrics.
